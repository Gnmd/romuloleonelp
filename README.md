# Dr. Rômulo Leone — Landing page

Site institucional do Dr. Rômulo Leone (médico residente em psiquiatria, CRM/SP 256.617), exportado do Hostinger Horizons.

Stack: React 18 + Vite 7 + Tailwind CSS 3 + shadcn/ui (Radix) + Framer Motion.

## Desenvolvimento

```bash
npm install      # instala dependências (workspaces)
npm run dev      # servidor local em http://localhost:3000
npm run build    # build de produção em dist/apps/web
npm run lint
```

O conteúdo da página está em `apps/web/src/App.jsx`; o cabeçalho em `apps/web/src/components/layout/Header.jsx`.
